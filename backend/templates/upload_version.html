Preparing the Update Package

The ZIP file should contain:

  1. The updated executable (e.g., SecureLicenseClient.exe)
  2. Any required DLL files (Qt libraries, etc.)
  3. Updated configuration files (if any)
  4. Any other necessary resources

Example structure:

update_v1.0.0.zip
├── SecureLicenseClient.exe
├── Qt6Core.dll
├── Qt6Gui.dll
├── Qt6Widgets.dll
├── Qt6Network.dll
└── platforms/
    └── qwindows.dll
Versioning Best Practices

Semantic Versioning (MAJOR.MINOR.PATCH):

  • MAJOR (1.0.0 → 2.0.0): Breaking changes, incompatible API changes
  • MINOR (1.0.0 → 1.1.0): New features, backward compatible
  • PATCH (1.0.0 → 1.0.1): Bug fixes, backward compatible

Examples: 1.0.0 (initial release), 1.1.0 (new features), 1.1.1 (bug fixes), 2.0.0 (major update)
