How Auto-Update Works
  1. Upload a new version ZIP file containing the updated application
  2. Set it as the "Current Version"
  3. Clients will automatically detect and download the update on startup
  4. The update will be applied and the application restarted

Note: Only one version can be marked as "Current" at a time. Setting a new current version will automatically unset the previous one.
